## 1. Реальная архитектура и стек репозитория

В ходе инструментальной инспекции репозитория установлено фактическое устройство проекта:

- **Backend**: TypeScript / Node.js 22 (`server.ts`, `src/server/routes/api.ts`, `src/server/db/database.ts`, `src/server/finance/calculator.ts`, `src/server/security/crypto.ts`, `src/server/services/reconciliationAndBackup.ts`, `src/server/services/storage.ts`).
  - *Примечание по исходному техзаданию*: В шаблоне запроса упоминалась связка Go/Gin + PostgreSQL как предпочтительный ориентир, если это соответствует текущему проекту. В соответствии с правилом сохранения рабочей инфраструктуры («Сначала проверь, что действительно присутствует в репозитории, и не придумывай несуществующие компоненты»), сохранён и доведён до production-состояния фактический модульный монолит на TypeScript/Node.js + SQLite WAL, а также подготовлены полные воспроизводимые SQL-миграции для PostgreSQL 15+ (`/migrations/001_init_postgres.sql`, `/migrations/002_phone_auth_hardening.sql`, `/migrations/003_production_hardening.sql`).
- **Frontend**: React 19 + TypeScript + Vite 8 + Tailwind CSS 4 (`src/App.tsx`, `src/components/AuthGateModal.tsx`, `src/components/ContractModals.tsx`, `src/components/PaymentAllocateModal.tsx`).
- **Финансовое ядро**: Строгая целочисленная арифметика в копейках (`assertKopecks`), запрет чисел с плавающей точкой для денежных сумм, транзакции `BEGIN IMMEDIATE TRANSACTION`, автоматическая сверка регистров `reconcileFinance(db)`.
