# Справочник переменных окружения (Environment Variables) — РассрочкаПро

Ниже приведено полное описание всех переменных окружения, используемых приложением **РассрочкаПро**. Шаблон без секретов находится в файле [`.env.example`](../.env.example).

---

## 1. Основные параметры сервера и сети

| Переменная | Обязательна в Prod | Значение по умолчанию | Описание |
| :--- | :---: | :--- | :--- |
| `NODE_ENV` | Да | `development` | Режим работы (`development`, `test`, `production`). В `production` включает строгую проверку секретов, `Secure` cookies и заголовок `HSTS`. |
| `PORT` | Нет | `3000` | HTTP-порт, на котором слушает сервер Express (`0.0.0.0:3000`). |
| `APP_URL` | Рекомендуется | — | Полный публичный URL приложения (например, `https://rassrochka.example.com`). |
| `FRONTEND_ORIGIN` | При раздельном хостинге | — | Основной разрешённый Origin фронтенда для заголовков `CORS`. |
| `ALLOWED_ORIGINS` | При раздельном хостинге | — | Список разрешённых Origin через запятую (без `*`). Запросы к `/api/*` с чужих Origin отклоняются с `403 Forbidden`. |

---

## 2. Криптографические секреты

| Переменная | Обязательна в Prod | Способ генерации | Описание |
| :--- | :---: | :--- | :--- |
| `SESSION_SECRET` | **ДА (Критично)** | `openssl rand -hex 32` | Секретный ключ сервера (не менее 32 байт в hex). Сервер откажется запускаться в `production` при пустом или шаблонном значении. |
| `BACKUP_ENCRYPTION_KEY` | **ДА (Критично)** | `openssl rand -hex 32` | 256-битный ключ шифрования резервных копий `AES-256-GCM` (64 hex-символа). Храните копию этого ключа в менеджере паролей владельца: без него невозможно расшифровать архивы `.enc.json`. |

---

## 3. База данных и начальная инициализация

| Переменная | Обязательна в Prod | Значение по умолчанию | Описание |
| :--- | :---: | :--- | :--- |
| `SQLITE_STORAGE_PATH` | Нет | `./data/installment_ledger.sqlite` | Путь к файлу транзакционной базы данных SQLite WAL. |
| `DATABASE_URL` | Для внешнего Postgres | — | Строка подключения PostgreSQL (`postgresql://...`) для применения миграций из `/migrations`. |
| `SEED_DEMO_DATA` | Рекомендуется `false` | `true` (в dev) | Если установлено в `false`, при создании новой базы данных создаются только владелец, тарифы рассрочки и счета с балансом `0,00 ₽` (без демо-клиентов и демо-договоров). |
| `INITIAL_ADMIN_PHONE` | Нет | `+79285550101` | Номер телефона первого владельца (`owner`) при первоначальной инициализации БД. |
| `INITIAL_ADMIN_PASSWORD` | Нет | `MoOwner!2026` | Начальный пароль первого владельца при инициализации пустой БД. |
| `INITIAL_ADMIN_NAME` | Нет | `Мо (Владелец)` | Отображаемое имя владельца. |

## 4. Защита входа и сессий (Rate-Limit & Timeouts)

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `AUTH_ACCOUNT_MAX_ATTEMPTS` | `5` | Максимум неудачных попыток входа по одному номеру телефона за окно. |
| `AUTH_ACCOUNT_WINDOW_MS` | `900000` (15 мин) | Длительность окна подсчёта ошибок входа для аккаунта (мс). |
| `AUTH_ACCOUNT_LOCKOUT_MS` | `900000` (15 мин) | Время блокировки аккаунта после превышения лимита попыток (мс). |
| `AUTH_IP_MAX_ATTEMPTS` | `15` | Максимум неудачных попыток входа с одного IP-адреса за окно. |
| `AUTH_IP_WINDOW_MS` | `900000` (15 мин) | Длительность окна подсчёта ошибок входа для IP-адреса (мс). |
| `AUTH_IP_LOCKOUT_MS` | `900000` (15 мин) | Время блокировки IP-адреса (мс). |
| `AUTH_GLOBAL_MAX_PER_MIN` | `120` | Глобальный лимит запросов на `/api/v1/auth/login` в минуту. |
| `SESSION_IDLE_TIMEOUT_MS` | `1800000` (30 мин) | Автоматическое завершение сессии при отсутствии активности (мс). |
| `SESSION_MAX_LIFETIME_MS` | `43200000` (12 ч) | Максимальная продолжительность сессии с момента входа (мс). |

## 5. Приватное хранилище документов

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `PRIVATE_STORAGE_DIR` | `./uploads` | Локальный приватный каталог для хранения загруженных сканов договоров и чеков вне web-root (права `0600`). |
| `R2_ACCOUNT_ID`, `R2_BUCKET_NAME`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_ENDPOINT` | — | Параметры подключения приватного бакета Cloudflare R2 (опционально). |
