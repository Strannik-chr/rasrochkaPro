# Контролируемая подготовка и очистка базы данных (Safe Database Reset) — РассрочкаПро

Документ описывает безопасный порядок инспекции и очистки демонстрационных/тестовых записей перед началом реальной коммерческой эксплуатации.

---

## 1. Золотое правило безопасности данных

- **Никакие существующие записи не удаляются автоматически без предварительного создания проверенной резервной копии и явного подтверждения владельца.**
- Перед любой очисткой система обязана создать и верифицировать зашифрованный снимок `AES-256-GCM` в каталоге `./backups/`.

## 3. Как выполнить подтверждённую очистку для чистого старта

### Шаг 1. Безопасная инспекция и создание свежего бэкапа (без удаления)
```bash
npm run db:inspect
```

### Шаг 2. Выполнение очистки с явным флагом подтверждения `--confirm-clean`
Если вы хотите удалить все демонстрационные договоры, платежи и клиентов, сохранив только владельца (`+79285550101`), системные тарифы рассрочки и нулевые балансы кассы/банка:
```bash
npm run db:clean -- --confirm-clean
```
*(Если вы также хотите сохранить учётные записи действующих операторов `staff`, добавьте флаг `--keep-staff`: `npm run db:clean -- --confirm-clean --keep-staff`).*

### Шаг 3. Как вернуть данные обратно при необходимости
Поскольку перед очисткой автоматически создаётся и проверяется зашифрованный бэкап, вы в любой момент можете восстановить все данные одной кнопкой **«Восстановить БД»** в разделе **«14. Безопасность и бэкапы»** или через `POST /api/v1/security/backups/<id>/restore`.
