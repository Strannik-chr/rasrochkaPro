# РассрочкаПро — Система управления продажами товаров в рассрочку и финансовый реестр

**РассрочкаПро** — защищённая production-система (модульный монолит) для учёта закупок товаров под клиента, договоров рассрочки с настраиваемой наценкой, версионируемых графиков платежей, ручного распределения частичных поступлений, двойной сверки кассы/банка и приватного хранения документов.

---

## 1. Архитектура и фактический стек проекта

- **Архитектура**: Модульный монолит (единый веб-сервер API + SPA-клиент + транзакционный слой хранения данных и приватное файловое хранилище вне публичного web-root).
- **Backend**: TypeScript / Node.js 22 (`express` 4, встроенный транзакционный движок `node:sqlite` в режиме `WAL` + `BEGIN IMMEDIATE TRANSACTION` + воспроизводимые SQL-миграции для PostgreSQL 15+ в `/migrations`).
- **Frontend**: React 19 + TypeScript + Vite 8 + Tailwind CSS 4 (адаптивный интерфейс для работы с компьютера и смартфона).
- **Безопасность**:
  - Вход исключительно по российскому номеру телефона (`+7XXXXXXXXXX`) и паролю (`scrypt` `N=16384, r=8, p=1`, соль 128 бит, ключ 512 бит, constant-time проверка).
  - Полный запрет самостоятельной регистрации; создание пользователей доступно только администратору (`owner`) или через защищённую серверную CLI-команду `npm run create-admin`.
  - Строгая проверка `X-CSRF-Token` на всех изменяющих запросах (`POST`, `PUT`, `PATCH`, `DELETE`), заголовки `CSP`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`, `HSTS` и строгий allowlist `CORS`.
  - Многоуровневый атомарный rate-limit в БД (5 попыток за 15 минут на нормализованный телефон, 15 попыток за 15 минут с одного IP, 120 запросов/мин глобально).
  - Зашифрованные резервные копии `AES-256-GCM` с проверкой `SHA-256` и сверкой всех финансовых регистров до и после восстановления.

## 2. Быстрый старт (локально и на сервере)

### Требования
- Node.js `>= 22.6.0`
- npm `>= 10.0.0`

### Установка и запуск
```bash
# 1. Установка зависимостей
npm install

# 2. Подготовка переменных окружения
cp .env.example .env
# Отредактируйте .env, указав уникальные SESSION_SECRET и BACKUP_ENCRYPTION_KEY (openssl rand -hex 32)

# 3. Создание или обновление первого администратора (owner)
npm run create-admin -- --phone "+79285550101" --password "ВашНадёжныйПароль!2026" --name "Мо (Владелец)"

# 4. Запуск в режиме разработки
npm run dev

# 5. Сборка и запуск в production-режиме
npm run build
npm start
```

## 3. Команды проверки, обслуживания и резервного копирования

| Команда | Назначение |
| :--- | :--- |
| `npm run lint` | Строгая проверка типов TypeScript (`tsc --noEmit`) без ошибок |
| `npm test` | Полный набор автоматических тестов: финансовая математика в копейках, RBAC, rate-limit, CSRF, приватные документы, Backup/Restore и Clean Reset |
| `npm run build` | Сборка оптимизированного клиентского бандла в `dist/` |
| `npm run create-admin` | Создание или сброс пароля первого администратора (`owner`) через CLI |
| `npm run db:inspect` | Инспекция всех таблиц БД и автоматическое создание + верификация зашифрованной резервной копии (`AES-256-GCM`) без удаления данных |
| `npm run db:clean -- --confirm-clean` | Контролируемая очистка демо/операционных данных с предварительным бэкапом и сохранением схемы, тарифов и администратора |
